API INTEGRATION PATTERNS
================================================================================

AUTHENTICATION SERVICE:
```typescript
class AuthService {
  async login(credentials: LoginRequest): Promise<LoginResponse>
  async logout(): Promise<void>
  async getProfile(): Promise<User>
  async refreshToken(): Promise<string>
}
```

USER SERVICE:
```typescript
class UserService {
  async getUsers(filters?: UserFilters): Promise<User[]>
  async getUserById(id: string): Promise<User>
  async createUser(userData: CreateUserRequest): Promise<User>
  async updateUser(id: string, userData: UpdateUserRequest): Promise<User>
  async deleteUser(id: string): Promise<void>
}
```

ROLE SERVICE:
```typescript
class RoleService {
  async getRoles(): Promise<Role[]>
  async getRoleById(id: string): Promise<Role>
  async createRole(roleData: CreateRoleRequest): Promise<Role>
  async updateRole(id: string, roleData: UpdateRoleRequest): Promise<Role>
  async deleteRole(id: string): Promise<void>
}
```

ERROR HANDLING REQUIREMENTS
================================================================================

NETWORK ERRORS:
- Show: "Unable to connect to server. Please check your connection."
- Action: Retry button, check network status

AUTHENTICATION ERRORS (401):
- Clear auth state
- Redirect to login
- Show: "Session expired. Please login again."

PERMISSION ERRORS (403):
- Show: "You don't have permission to perform this action."
- Hide unavailable features
- Disable action buttons

VALIDATION ERRORS (400):
- Show field-specific error messages
- Highlight invalid fields
- Prevent form submission

CONFLICT ERRORS (409):
- Show: "Username/Email already exists"
- Highlight conflicting fields
- Suggest alternatives

RATE LIMIT ERRORS (429):
- Show: "Too many attempts. Please try again in X minutes."
- Disable submit button with countdown
- Implement exponential backoff

BACKEND API REFERENCE
================================================================================

All API endpoints are documented in: FRONTEND_API_INTEGRATION_GUIDE.txt
Base URL: http://localhost:3000/api/v1
Authentication: JWT Bearer Token
Response Format: { success, message, data, timestamp }

Key Endpoints:
- POST /auth/login - User authentication
- GET /auth/profile - Get current user
- POST /auth/logout - User logout
- GET /users - List all users (admin only)
- POST /users - Create user (admin only)
- PUT /users/:id - Update user
- DELETE /users/:id - Delete user (admin only)
- GET /roles - List all roles
- POST /roles - Create role (admin only)
- PUT /roles/:id - Update role (admin only)
- DELETE /roles/:id - Delete role (admin only)
