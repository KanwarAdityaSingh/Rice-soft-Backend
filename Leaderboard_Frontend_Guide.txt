
================================================================================
SECTION 1: LEADERBOARD OVERVIEW
================================================================================

The leaderboard tracks and ranks salespeople based on their performance metrics.
It provides insights into sales team performance, individual achievements, and
team-wide statistics.

KEY METRICS:
1. Total Leads - Number of leads assigned to a salesperson
2. Converted Leads - Number of leads successfully converted
3. Conversion Rate - Percentage of leads converted (converted/total * 100)
4. Total Revenue - Sum of all conversion values
5. Average Deal Size - Average value of converted deals (revenue/conversions)
6. Performance Score - Weighted score combining all metrics

PERFORMANCE SCORE CALCULATION:
The performance score is a weighted combination:
- Conversion Rate: 40% weight
- Total Revenue: 30% weight (normalized to 100)
- Total Leads: 20% weight (normalized to 100)
- Average Deal Size: 10% weight (normalized to 100)

SCORE RANGE: 0-100 (higher is better)

USE CASES:
- Track individual salesperson performance
- Team performance overview
- Identify top performers
- Monitor conversion metrics
- Generate performance reports

// api/leaderboard.js
export const leaderboardAPI = {
  getLeaderboard: (filters) => {
    let url = `${API_BASE_URL}/leaderboard/getLeaderboard`;
    const params = new URLSearchParams();
    if (filters.start_date) params.append('start_date', filters.start_date);
    if (filters.end_date) params.append('end_date', filters.end_date);
    if (filters.sort_by) params.append('sort_by', filters.sort_by);
    if (filters.sort_order) params.append('sort_order', filters.sort_order);
    if (filters.limit) params.append('limit', filters.limit);
    if (filters.offset) params.append('offset', filters.offset);
    if (params.toString()) url += `?${params.toString()}`;
    return axios.get(url);
  },
  
  getTeamStats: () => 
    axios.get(`${API_BASE_URL}/leaderboard/getTeamStats`),
  
  getSalespersonStats: (id, timeRange) => {
    let url = `${API_BASE_URL}/leaderboard/getSalespersonStats/${id}`;
    const params = new URLSearchParams();
    if (timeRange?.start_date) params.append('start_date', timeRange.start_date);
    if (timeRange?.end_date) params.append('end_date', timeRange.end_date);
    if (params.toString()) url += `?${params.toString()}`;
    return axios.get(url);
  },
  
  getSalespersonDetailStats: (id) => 
    axios.get(`${API_BASE_URL}/leaderboard/getSalespersonDetailStats/${id}`),
  
  getMonthlyTrends: (id) => 
    axios.get(`${API_BASE_URL}/leaderboard/getSalespersonMonthlyTrends/${id}`),
  
  getRecentActivities: (id, limit) => {
    let url = `${API_BASE_URL}/leaderboard/getSalespersonRecentActivities/${id}`;
    if (limit) url += `?limit=${limit}`;
    return axios.get(url);
  }
};

const [dateRange, setDateRange] = useState({
  start_date: null,
  end_date: null

PRESET OPTIONS:
- Today
- This Week
- This Month
- This Quarter
- This Year
- Last 7 Days
- Last 30 Days
- Last 90 Days
- Custom Range

function applyDateRange(rangeType) {
  const today = new Date();
  let start, end;
  
  switch(rangeType) {
    case 'this_month':
      start = new Date(today.getFullYear(), today.getMonth(), 1);
      end = today;
      break;
    case 'this_quarter':
      const quarter = Math.floor(today.getMonth() / 3);
      start = new Date(today.getFullYear(), quarter * 3, 1);
      end = today;
      break;
    case 'this_year':
      start = new Date(today.getFullYear(), 0, 1);
      end = today;
      break;
  }
  
  setDateRange({
    start_date: formatDate(start),
    end_date: formatDate(end)
  });
}

function formatDate(date) {
  return date.toISOString().split('T')[0]; // YYYY-MM-DD
}

SECTION 9: ERROR HANDLING
================================================================================

Common Leaderboard API Errors:

404 Not Found:
- "Salesperson not found or has no leads"
  → Show message that salesperson has no data yet
  → Display empty state with message
  → Suggest assigning leads to this salesperson

400 Bad Request:
- Invalid date format
- Invalid sort_by or sort_order values
  → Show validation error message
  → Reset to default values

401 Unauthorized:
- Handle token expiration
- Redirect to login

EMPTY STATES:
When no salespeople have leads:
- Show message: "No leaderboard data available yet"
- Suggest: "Assign leads to salespeople to see performance metrics"

When salesperson has no activity:
- Show message: "No activity recorded for this period"
- Suggest: "Try selecting a different date range"

SECTION 10: IMPORTANT NOTES
================================================================================

1. PERFORMANCE SCORE:
   - Calculated server-side using weighted formula
   - Normalizes each metric to 0-100 range
   - Higher score indicates better overall performance
   - Considers conversion rate most heavily (40%)

2. DATE RANGE FILTERING:
   - Filters based on lead creation date
   - End date should be inclusive
   - Use ISO format (YYYY-MM-DD)
   - Always validate date range (start <= end)

3. PAGINATION:
   - Use limit and offset for large teams
   - Show total_count for total pages calculation
   - Default limit can be set on frontend (e.g., 20 per page)

4. SORTING:
   - Can sort by: total_leads, conversion_rate, total_revenue, performance_score
   - Default sort by performance_score descending
   - Toggle between asc/desc on frontend

5. LEADERBOARD ENTRIES:
   - Only shows salespeople with at least 1 lead
   - Users with user_type = 'salesman' are eligible
   - Inactive salesmen included if they have leads

6. TREND DATA:
   - Monthly trends show last 12 months
   - Data grouped by month (YYYY-MM format)
   - Shows all months in range, even with 0 leads
   - Sort descending (newest first)

7. RECENT ACTIVITIES:
   - Shows both lead creation and conversion
   - Limited to recent 10 activities by default
   - Can customize limit via query parameter
   - Sort by timestamp descending

8. TEAM STATS:
   - Aggregates data from all salespeople
   - Top performer calculated separately
   - Shows overall team performance
   - Useful for management dashboards

9. CONVERSION METRICS:
   - Conversion rate = (converted_leads / total_leads) * 100
   - Revenue comes from conversions table (conversion_value)
   - Average deal size = total_revenue / converted_leads
   - Only calculated when there are conversions

10. SALESPERSON SELECTION:
    - Need to get salesperson IDs from /salesmen/getAllSalesmen
    - Or from /users/getAllUsers with user_type=salesman
    - Store salesperson mapping for display names
    - Link leaderboard to salesperson profile pages
