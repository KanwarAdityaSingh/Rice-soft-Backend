================================================================================
GOOGLE MAPS LOCATION LINK FEATURE - FRONTEND IMPLEMENTATION
================================================================================

OVERVIEW:
The backend now supports storing Google Maps location links/Plus Codes for leads and vendors.
When a Google Maps link is provided, the backend automatically extracts latitude/longitude
coordinates from it. This allows users to paste a Google Maps URL instead of manually
entering coordinates.

================================================================================
BACKEND API CHANGES
================================================================================

1. NEW FIELD:
   - Field name: `google_location_link` (string, optional, max 500 chars)
   - Available in: Lead create/update, Vendor create/update endpoints

2. BEHAVIOR:
   - For LEADS: If `google_location_link` is provided AND `salesman_latitude`/`salesman_longitude`
     are NOT provided, the backend automatically extracts coordinates from the link and sets
     `salesman_latitude` and `salesman_longitude`.
   - For VENDORS: The `google_location_link` is stored as-is (no coordinate extraction yet).

3. RESPONSE:
   - All lead/vendor responses now include `google_location_link: string | null`

- User pastes link in "Google Maps Location Link" field
- System shows: "Coordinates will be extracted automatically"
- User submits form
- Backend extracts coordinates and stores both link and coordinates
- Response includes both `google_location_link` and `salesman_latitude`/`salesman_longitude`

SCENARIO 2: User provides both link and coordinates
- User pastes link AND manually enters coordinates
- Coordinates take priority (backend behavior)
- Both are stored, but coordinates are used for location

SCENARIO 3: User provides coordinates only
- User manually enters coordinates (existing behavior)
- No link stored
- Works as before

SCENARIO 4: User provides neither
- Both fields optional
- No location data stored

6. VALIDATION RULES
================================================================================

- `google_location_link`: 
  - Optional field
  - If provided, should be a valid URL or Plus Code format
  - Max length: 500 characters
  - Common formats to accept:
    * https://maps.google.com/?q=lat,lng
    * https://www.google.com/maps/place/.../@lat,lng
    * https://goo.gl/maps/...
    * https://maps.app.goo.gl/...
    * Plus Code format: "8FVC+2X Mumbai" or similar

================================================================================

7. ERROR HANDLING
================================================================================

- If backend fails to extract coordinates from link:
  - Backend will still store the link
  - Coordinates will remain null
  - Frontend should handle this gracefully (show link but no coordinates)

- If invalid link format:
  - Frontend validation should catch this before submission
  - Show error: "Invalid Google Maps link format"

9. EXAMPLE IMPLEMENTATION
================================================================================

LEAD CREATE FORM:
```typescript
// Add to form state
const [googleLocationLink, setGoogleLocationLink] = useState<string>('');

// Add to form JSX
<TextField
  label="Google Maps Location Link"
  name="google_location_link"
  value={googleLocationLink}
  onChange={(e) => setGoogleLocationLink(e.target.value)}
  placeholder="Paste Google Maps link or Plus Code"
  helperText="Coordinates will be automatically extracted from the link"
  fullWidth
  optional
/>

// Add to submit payload
const payload = {
  ...otherFields,
  google_location_link: googleLocationLink || undefined,
  // salesman_latitude and salesman_longitude can still be provided manually
};
```

LEAD DETAIL VIEW:
```typescript
{lead.google_location_link && (
  <Button
    href={lead.google_location_link}
    target="_blank"
    rel="noopener noreferrer"
  >
    Open Location in Google Maps
  </Button>
)}
```

- The link is stored for reference even if coordinates are extracted
- Plus Code support is prepared in backend but may need additional library for full support
