===========================================
IMAGE & DOCUMENT DISPLAY
FRONTEND IMPLEMENTATION GUIDE
===========================================

## OVERVIEW

The backend stores and returns URLs for uploaded images and documents across multiple entities. These URLs are S3 URLs that can be directly used in the frontend to display images or download documents.

---

## ENTITIES WITH IMAGE/DOCUMENT URLS

### 1. Sauda (Rice Deal)
- `cooked_rice_image_url` - Image of cooked rice sample
- `uncooked_rice_image_url` - Image of uncooked rice sample

### 2. Inward Slip Pass (ISP)
- `inward_slip_bill_image_url` - Inward slip bill image
- `transportation_bill_image_url` - Transportation bill image
- `bill_pdf_url` - Purchase bill (can be PDF or image)
- `bilti_image_url` - Bilti/LR image
- `bilti_pdf_url` - Bilti/LR PDF
- `eway_bill_url` - E-way bill document

### 3. Payment Advice
- `payment_slip_image_url` - Payment slip/receipt image

## FRONTEND IMPLEMENTATION

### 1. Basic Image Display Component

```typescript
interface ImageDisplayProps {
  url: string | null;
  alt: string;
  fallbackText?: string;
}

const ImageDisplay: React.FC<ImageDisplayProps> = ({ 
  url, 
  alt, 
  fallbackText = "No image available" 
}) => {
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(false);

  if (!url) {
    return (
      <div className="no-image-placeholder">
        <p>{fallbackText}</p>
      </div>
    );
  }

  return (
    <div className="image-container">
      {loading && <div className="loading-spinner">Loading...</div>}
      {error && <div className="error-message">Failed to load image</div>}
      <img
        src={url}
        alt={alt}
        onLoad={() => setLoading(false)}
        onError={() => {
          setLoading(false);
          setError(true);
        }}
        style={{ display: loading || error ? 'none' : 'block' }}
      />
    </div>
  );
};
```

### 2. Document/PDF Display Component

```typescript
interface DocumentDisplayProps {
  url: string | null;
  fileName?: string;
  type?: 'pdf' | 'image';
}

const DocumentDisplay: React.FC<DocumentDisplayProps> = ({ 
  url, 
  fileName = "Document",
  type 
}) => {
  if (!url) {
    return <p>No document available</p>;
  }

  // Determine type from URL if not provided
  const isPdf = type === 'pdf' || url.toLowerCase().endsWith('.pdf');

  const handleDownload = () => {
    const link = document.createElement('a');
    link.href = url;
    link.download = fileName;
    link.target = '_blank';
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  };

  const handleView = () => {
    window.open(url, '_blank');
  };

  return (
    <div className="document-display">
      {isPdf ? (
        <div className="pdf-controls">
          <button onClick={handleView}>View PDF</button>
          <button onClick={handleDownload}>Download PDF</button>
        </div>
      ) : (
        <div className="image-preview">
          <img src={url} alt={fileName} />
          <button onClick={handleDownload}>Download</button>
        </div>
      )}
    </div>
  );
};
```

### 3. Image Gallery Component (for multiple images)

```typescript
interface ImageGalleryProps {
  images: Array<{
    url: string | null;
    label: string;
  }>;
}

const ImageGallery: React.FC<ImageGalleryProps> = ({ images }) => {
  const [selectedImage, setSelectedImage] = useState<string | null>(null);

  const validImages = images.filter(img => img.url !== null);

  if (validImages.length === 0) {
    return <p>No images available</p>;
  }

  return (
    <div className="image-gallery">
      <div className="thumbnail-grid">
        {validImages.map((image, index) => (
          <div 
            key={index} 
            className="thumbnail-item"
            onClick={() => setSelectedImage(image.url)}
          >
            <img src={image.url!} alt={image.label} />
            <p>{image.label}</p>
          </div>
        ))}
      </div>

      {selectedImage && (
        <div className="lightbox" onClick={() => setSelectedImage(null)}>
          <div className="lightbox-content" onClick={(e) => e.stopPropagation()}>
            <button 
              className="close-button" 
              onClick={() => setSelectedImage(null)}
            >
              ×
            </button>
            <img src={selectedImage} alt="Full size" />
          </div>
        </div>
      )}
    </div>
  );
};
```

## IMPORTANT NOTES

### 1. URL Format
- All URLs are complete S3 URLs
- URLs are publicly accessible (no signing required)
- URLs can be used directly in `<img>` tags or `href` attributes

### 2. Null Handling
- All image/document URL fields can be `null`
- Always check for `null` before rendering
- Provide appropriate fallback UI for missing images

### 3. File Types
- Image fields typically contain: `.jpg`, `.jpeg`, `.png`, `.gif`
- PDF fields contain: `.pdf`
- Some fields (like `bill_pdf_url`) can contain either images or PDFs
- Check file extension or content-type if needed

### 4. Performance Considerations
- Consider lazy loading images in lists
- Use thumbnail versions if available (currently not implemented)
- Implement image caching on frontend
- Show loading states while images load

### 5. Error Handling
- Handle 404 errors (image not found)
- Handle network errors
- Provide retry mechanism for failed loads
- Show appropriate error messages
