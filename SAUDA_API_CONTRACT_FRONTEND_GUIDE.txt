1. CREATE SAUDA
================================================================================

Endpoint: POST /api/v1/saudas
Method: POST
Authentication: Required
Content-Type: application/json

REQUEST BODY:
{
  "sauda_type": string (REQUIRED) - must be one of: "exgodown", "for",
  "rice_type": string (REQUIRED) - must be one of: "basmati", "non_basmati", 
    "parboiled", "raw", "raw_basmati", "steam_basmati", "white_sella", "golden_sella",
  "rice_code_id": string (optional, UUID, can be null),
  "rate": number (REQUIRED, minimum 0, precision 2 decimal places),
  "broker_id": string (optional, UUID, can be null),
  "broker_commission": number (optional, minimum 0, precision 2, can be null),
  "broker_commission_type": string (optional, default: "percentage") - must be one of: 
    "rupees", "percentage", "weight",
  "quantity": number (optional, minimum 0, precision 2, can be null),
  "cash_discount": number (optional, minimum 0, precision 2, can be null),
  "cash_discount_type": string (optional, default: "rupees") - must be one of: 
    "rupees", "percentage",
  "estimated_delivery_time": number (optional, integer, minimum 0, can be null) - in days,
  "purchaser_id": string (REQUIRED, UUID) - must be a valid vendor ID,
  "cooked_rice_image_url": string (optional, valid URI, can be null or empty),
  "uncooked_rice_image_url": string (optional, valid URI, can be null or empty),
  "status": string (optional) - must be one of: "draft", "active", "completed", "cancelled",
  "notes": string (optional, max 1000 chars, can be null or empty),
  "is_dana_required": boolean (optional, default: true)
}

IMPORTANT VALIDATION RULES:
- purchaser_id MUST exist in the vendors table
- broker_id (if provided) MUST exist in the brokers table
- rice_code_id (if provided) MUST exist in the rice_codes table
- rate must be a positive number with up to 2 decimal places
- All numeric fields (rate, broker_commission, quantity, cash_discount) must be >= 0
- estimated_delivery_time must be a non-negative integer (days)

SUCCESS RESPONSE (201 Created):
{
  "success": true,
  "message": "Sauda created successfully",
  "data": {
    "id": "uuid",
    "sauda_type": "exgodown" | "for",
    "rice_type": "basmati" | "non_basmati" | "parboiled" | "raw" | "raw_basmati" | 
      "steam_basmati" | "white_sella" | "golden_sella",
    "rice_code_id": "uuid or null",
    "rate": number,
    "broker_id": "uuid or null",
    "broker_commission": number or null,
    "broker_commission_type": "rupees" | "percentage" | "weight",
    "quantity": number or null,
    "received_until_now": number (default: 0),
    "completion_percentage": number or null,
    "cash_discount": number or null,
    "cash_discount_type": "rupees" | "percentage",
    "estimated_delivery_time": number or null,
    "purchaser_id": "uuid",
    "cooked_rice_image_url": "string or null",
    "uncooked_rice_image_url": "string or null",
    "status": "draft" | "active" | "completed" | "cancelled",
    "notes": "string or null",
    "is_dana_required": boolean,
    "created_at": "ISO 8601 timestamp string",
    "updated_at": "ISO 8601 timestamp string"
  },
  "timestamp": "ISO 8601 timestamp string",
  "isSessionValid": true
}

ERROR RESPONSES:

400 Bad Request - Validation Error:
{
  "success": false,
  "message": "Validation error message",
  "error": "Detailed validation error",
  "timestamp": "ISO 8601 timestamp string",
  "isSessionValid": true
}

Common validation errors:
- "sauda_type is required"
- "sauda_type must be one of: exgodown, for"
- "rice_type is required"
- "rice_type must be one of: basmati, non_basmati, parboiled, raw, raw_basmati, steam_basmati, white_sella, golden_sella"
- "rate is required"
- "rate must be a number"
- "rate must be greater than or equal to 0"
- "purchaser_id is required"
- "purchaser_id must be a valid UUID"
- "Invalid reference: purchaser, broker, or rice code does not exist"

404 Not Found:
{
  "success": false,
  "message": "Resource not found",
  "error": "Purchaser (vendor) not found" | "Broker not found" | "Rice code not found",
  "timestamp": "ISO 8601 timestamp string",
  "isSessionValid": true
}

409 Conflict - Duplicate Data:
{
  "success": false,
  "message": "Conflict error message",
  "error": "A sauda with this information already exists",
  "timestamp": "ISO 8601 timestamp string",
  "isSessionValid": true
}

500 Internal Server Error:
{
  "success": false,
  "message": "An unexpected error occurred",
  "error": "Failed to create sauda. Please try again." | "Error details (in development)",
  "timestamp": "ISO 8601 timestamp string",
  "isSessionValid": true
}

2. UPDATE SAUDA
================================================================================

Method: PUT
Authentication: Required
Content-Type: application/json

URL PARAMETERS:

REQUEST BODY:
All fields are OPTIONAL, but at least one field must be provided:
{
  "sauda_type": string (optional) - must be one of: "exgodown", "for",
  "rice_type": string (optional) - must be one of: "basmati", "non_basmati", 
    "parboiled", "raw", "raw_basmati", "steam_basmati", "white_sella", "golden_sella",
  "rice_code_id": string (optional, UUID, can be null),
  "rate": number (optional, minimum 0, precision 2),
  "broker_id": string (optional, UUID, can be null),
  "broker_commission": number (optional, minimum 0, precision 2, can be null),
  "broker_commission_type": string (optional) - must be one of: "rupees", "percentage", "weight",
  "quantity": number (optional, minimum 0, precision 2, can be null),
  "cash_discount": number (optional, minimum 0, precision 2, can be null),
  "cash_discount_type": string (optional) - must be one of: "rupees", "percentage",
  "estimated_delivery_time": number (optional, integer, minimum 0, can be null),
  "purchaser_id": string (optional, UUID),
  "cooked_rice_image_url": string (optional, valid URI, can be null or empty),
  "uncooked_rice_image_url": string (optional, valid URI, can be null or empty),
  "status": string (optional) - must be one of: "draft", "active", "completed", "cancelled",
  "notes": string (optional, max 1000 chars, can be null or empty),
  "is_dana_required": boolean (optional)
}

IMPORTANT NOTES:
- At least one field must be provided in the request body
- If updating purchaser_id, broker_id, or rice_code_id, they must exist in their respective tables

4. GET ALL SAUDAS
================================================================================

Endpoint: GET /api/v1/saudas
Method: GET
Authentication: Required

QUERY PARAMETERS (all optional):
- include_inactive: boolean (default: false) - Set to "true" to include inactive saudas
- status: string (optional) - Filter by status: "draft", "active", "completed", "cancelled"
- sauda_type: string (optional) - Filter by type: "exgodown" or "for"
- purchaser_id: string (optional, UUID) - Filter by purchaser ID

EXAMPLES:
GET /api/v1/saudas
GET /api/v1/saudas?include_inactive=true
GET /api/v1/saudas?status=active
GET /api/v1/saudas?sauda_type=exgodown
GET /api/v1/saudas?purchaser_id=123e4567-e89b-12d3-a456-426614174000
GET /api/v1/saudas?status=active&sauda_type=for&purchaser_id=123e4567-e89b-12d3-a456-426614174000

SUCCESS RESPONSE (200 OK):

11. SEND SAUDA VIA WHATSAPP
================================================================================

Endpoint: POST /api/v1/saudas/:id/send-via-whatsapp
Method: POST
Authentication: Required
Content-Type: multipart/form-data (if file is provided) or application/json

URL PARAMETERS:
- id: string (REQUIRED) - UUID of the sauda

REQUEST BODY (JSON or Form Data):
{
  "whatsappNumbers": array (REQUIRED, minimum 1 number) [
    "string (WhatsApp phone number)"
  ],
  "pdfUrl": string (optional) - URL of PDF file already uploaded to S3
  "file": File (optional) - PDF file to upload and attach
  - Maximum file size: 10MB
  - Allowed MIME type: application/pdf

- Either pdfUrl OR file must be provided (file will be uploaded to S3 first)

- Messages are sent to all numbers in the array
- Some numbers may fail while others succeed - check the results array

- 500 Internal Server Error: Server errors, database errors, external service failures

6. Handle 500 errors by showing a generic error message and asking user to retry
7. Check "isSessionValid" to determine if user needs to re-authenticate
8. For WhatsApp endpoints, always check the "results" array for individual success/failure

================================================================================
BUSINESS LOGIC NOTES
================================================================================

1. SAUDA TYPES:
   - "exgodown": Sauda for ex-godown (warehouse) transactions
   - "for": Sauda for forward transactions

2. STATUS FLOW:
   - draft: Initial state, can be edited freely
   - active: Sauda is active and in progress
   - completed: Sauda is completed
   - cancelled: Sauda is cancelled

3. COMMISSION TYPES:
   - "rupees": Fixed commission in rupees
   - "percentage": Commission as percentage of rate
   - "weight": Commission based on weight

4. CASH DISCOUNT:
   - "rupees": Fixed discount in rupees
   - "percentage": Discount as percentage of rate

5. RECEIVED UNTIL NOW:
   - Automatically calculated based on received quantities
   - Starts at 0 for new saudas
   - Updated when lots/purchases are received

6. COMPLETION PERCENTAGE:
   - Calculated based on received_until_now / quantity
   - Only available if quantity is set
   - Automatically updated

7. DANA REQUIREMENT:
   - is_dana_required: Indicates if dana (husk) deduction is required
   - Defaults to true
   - Used in purchase calculations
