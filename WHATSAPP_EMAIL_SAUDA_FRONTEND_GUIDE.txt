QUICK START: Messages are auto-generated by the backend. Frontend just needs to 
provide IDs and recipients. No template knowledge required!

================================================================================
                            API ENDPOINTS
================================================================================

IMPORTANT: Base URL Configuration
----------------------------------
If your frontend base URL is: http://localhost:3000/api/v1
Then use endpoints like: /saudas/:id/send-via-email

If your frontend base URL is: http://localhost:3000
Then use endpoints like: /api/v1/saudas/:id/send-via-email

⚠️  Common Error: Avoid duplicate /v1 in URL
❌ Wrong: http://localhost:3000/api/v1/v1/saudas/...
✅ Correct: http://localhost:3000/api/v1/saudas/...

All endpoints require: Authorization: Bearer <token>

| Method | Endpoint                        | Purpose                           |
|--------|--------------------------------|-----------------------------------|
| POST   | /api/v1/saudas/:id/send-via-email            | Send sauda via email (auto-generated message) |
| POST   | /api/v1/saudas/:id/send-via-whatsapp         | Send sauda via WhatsApp (auto-generated message) |
| POST   | /api/v1/saudas/send-payment-advice-email     | Send payment advice via email |
| POST   | /api/v1/saudas/send-payment-advice-whatsapp  | Send payment advice via WhatsApp |
| GET    | /api/v1/saudas/:id/notification-preview      | Preview message (optional - for editing) |

================================================================================
                        1. SEND SAUDA VIA EMAIL
================================================================================

POST /api/v1/saudas/:saudaId/send-via-email

Required:
- saudaId (URL parameter)
- emails: string[] (recipient email addresses)

Optional:
- file: PDF file
- customSubject, customHtml, customText (only if editing preview)

Example:
--------
// If your API_BASE_URL is "http://localhost:3000/api/v1"
const response = await fetch(`${API_BASE_URL}/saudas/${saudaId}/send-via-email`, {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}` },
  body: formData
});

// OR if your API_BASE_URL is "http://localhost:3000"
const response = await fetch(`${API_BASE_URL}/api/v1/saudas/${saudaId}/send-via-email`, {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}` },
  body: formData
});

// FormData setup:
const formData = new FormData();
formData.append('emails', JSON.stringify(['vendor@example.com']));
if (pdfFile) formData.append('file', pdfFile);

Response:
---------
{
  "status": "success",
  "data": {
    "sent": true,
    "messageId": "abc123",
    "recipients": ["vendor@example.com"]
  }
}

================================================================================
                       2. SEND SAUDA VIA WHATSAPP
================================================================================

POST /api/v1/saudas/:saudaId/send-via-whatsapp

Required:
- saudaId (URL parameter)
- whatsappNumbers: string[] (10-digit numbers or with country code)

Optional:
- file: PDF (auto-uploaded to S3)
- pdfUrl: string (existing PDF URL)
- customMessage: string (only if editing preview)

Phone Format:
- 10 digits: "9876543210" → auto-prefixed with 91
- With country: "919876543210"

Example:
--------
const formData = new FormData();
formData.append('whatsappNumbers', JSON.stringify(['9876543210']));
if (pdfFile) formData.append('file', pdfFile);

// Adjust based on your API_BASE_URL (see Email example above)
const response = await fetch(`${API_BASE_URL}/saudas/${saudaId}/send-via-whatsapp`, {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}` },
  body: formData
});

Response:
---------
{
  "status": "success",
  "data": {
    "sent": true,
    "results": [
      { "number": "919876543210", "success": true, "messageId": "wamid.xxx" }
    ],
    "summary": { "total": 1, "success": 1, "failed": 0 }
  }
}

Note: Check summary.failed for partial failures in WhatsApp.

================================================================================
                        6. ERROR HANDLING
================================================================================

Standard Error Response:
{
  "status": "error",
  "message": "Error description",
  "error_code": "ERROR_CODE"
}

WhatsApp Partial Failure:
- Response status is still "success"
- Check data.summary.failed > 0
- Check individual results[].success for each number

Example Error Handling:
------------------------
try {
  const response = await fetch(url, options);
  const result = await response.json();
  
  if (result.status !== 'success') {
    throw new Error(result.message);
  }
  
  // For WhatsApp, check for partial failures
  if (result.data.summary?.failed > 0) {
    const failed = result.data.results
      .filter(r => !r.success)
      .map(r => `${r.number}: ${r.error}`);
    console.warn('Some messages failed:', failed);
  }
} catch (error) {
  console.error('Send failed:', error.message);
}

                        7. SIMPLE REACT EXAMPLE
================================================================================

// Minimal implementation - just send with auto-generated messages
const SendSaudaButton = ({ saudaId }) => {
  const [emails, setEmails] = useState(['']);
  const [loading, setLoading] = useState(false);
  const API_BASE_URL = 'http://localhost:3000/api/v1'; // Adjust to your base URL

  const handleSend = async () => {
    setLoading(true);
    try {
      const formData = new FormData();
      formData.append('emails', JSON.stringify(emails.filter(e => e.trim())));
      
      // Use API_BASE_URL to avoid duplicate /v1
      const response = await fetch(`${API_BASE_URL}/saudas/${saudaId}/send-via-email`, {
        method: 'POST',
        headers: { 'Authorization': `Bearer ${token}` },
        body: formData
      });
      
      const result = await response.json();
      if (result.status === 'success') {
        alert('Sent successfully!');
      }
    } catch (error) {
      alert('Failed to send');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div>
      <input 
        type="email" 
        value={emails[0]} 
        onChange={(e) => setEmails([e.target.value])}
        placeholder="vendor@example.com"
      />
      <button onClick={handleSend} disabled={loading}>
        {loading ? 'Sending...' : 'Send Email'}
      </button>
    </div>
  );
};
