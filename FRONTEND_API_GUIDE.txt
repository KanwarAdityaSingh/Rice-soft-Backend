4.2 CREATE USER 
================================================================================

API ENDPOINT:
POST http://localhost:3000/api/v1/users/createUser

HEADERS:
Authorization: Bearer {token}
Content-Type: application/json

REQUEST BODY:
{
  "username": "john_sales",
  "email": "john@example.com",
  "password": "password123",
  "full_name": "John Salesman",
  "phone": "9876543210",
  "user_type": "salesman"

REQUIRED FIELDS:
- username (string, unique)
- email (string, valid email, unique)
- password (string, min 6 characters)
- full_name (string)
- user_type (enum: admin, salesman, vendor, broker, custom)

OPTIONAL FIELDS:
- phone (string)

SUCCESS RESPONSE (201):

  "success": true,
  "message": "User created successfully",
  "data": {

    "email": "john@example.com",

    "last_login": null,
    "created_at": "2025-10-27T10:49:03.240Z",
    "updated_at": "2025-10-27T10:49:03.240Z"
  },
  "timestamp": "2025-10-27T10:49:03.249Z"
}

ERROR RESPONSES:
- 409: Username or email already exists
- 400: Validation error (e.g., password too short, invalid email)
- 401: Unauthorized (invalid or missing token)

FORM VALIDATION:
Client-side validation before API call:
- Username: required, alphanumeric
- Email: required, valid email format
- Password: required, minimum 6 characters
- Full Name: required
- User Type: required, must be valid enum value
- Phone: optional, if provided validate format

IMPLEMENTATION:
1. Show create user form (modal or separate page)
2. On submit, validate client-side
3. Call API with form data
4. On success: Show success message, close form, refresh users list
5. On error: Display error message from API response

SECTION 5: ERROR HANDLING & AUTHENTICATION
================================================================================

TOKEN EXPIRATION:
JWT tokens expire in 24 hours. Implement:

1. Token validation on app load:
   - Check if token exists in localStorage
   - If no token → redirect to /login
   - If token exists → verify it's still valid (optional)

2. Token refresh logic:
   - On 401 error, redirect to /login
   - Clear localStorage
   - Show "Session expired" message

3. Auto logout on token expiry:
   - Check token expiration before making API calls
   - Or handle 401 errors globally

API ERROR HANDLING:

Standard Error Response Format:
{
  "success": false,
  "error": "Error message",
  "message": "Optional detailed message",
  "timestamp": "..."
}

Error Status Codes:
- 400: Bad Request (validation errors)
- 401: Unauthorized (invalid/missing token)
- 403: Forbidden (insufficient permissions)
- 404: Not Found (resource doesn't exist)
- 409: Conflict (duplicate username/email)
- 500: Internal Server Error

Handle errors by showing user-friendly messages:
- 401 → "Session expired. Please login again." → Redirect to /login
- 409 → "Username already exists. Please choose another."
- 400 → Show validation errors from response
- 500 → "Something went wrong. Please try again later."

SECTION 6: API SERVICE IMPLEMENTATION
================================================================================

Suggested API service structure:

// api.js
const API_BASE_URL = 'http://localhost:3000/api/v1';

// Get token from localStorage
const getToken = () => localStorage.getItem('token');

// Axios interceptor to add token to all requests
axios.interceptors.request.use(config => {
  const token = getToken();
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// Handle 401 errors globally
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // Clear storage and redirect to login
      localStorage.clear();
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

// API methods
export const authAPI = {
  login: (username, password) => 
    axios.post(`${API_BASE_URL}/auth/loginUser`, { username, password })
};

export const usersAPI = {
  getAll: (includeInactive = false, userType = null) => {
    let url = `${API_BASE_URL}/users/getAllUsers`;
    const params = new URLSearchParams();
    if (includeInactive) params.append('include_inactive', 'true');
    if (userType) params.append('user_type', userType);
    if (params.toString()) url += `?${params.toString()}`;
    return axios.get(url);
  },
  
  getById: (id) => 
    axios.get(`${API_BASE_URL}/users/getUserById/${id}`),
  
  create: (userData) => 
    axios.post(`${API_BASE_URL}/users/createUser`, userData),
  
  update: (id, userData) => 
    axios.post(`${API_BASE_URL}/users/updateUser/${id}`, userData),
  
  delete: (id) => 
    axios.post(`${API_BASE_URL}/users/deleteUser/${id}`)
};

// Usage in components
const response = await usersAPI.getAll();
const users = response.data.data;
