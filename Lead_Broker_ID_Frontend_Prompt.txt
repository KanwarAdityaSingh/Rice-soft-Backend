LEAD BROKER ID FIELD - FRONTEND INTEGRATION GUIDE

API CHANGES:
============

1. Lead Model Update:
   - All Lead API responses now include `broker_id` field (nullable string/UUID)
   - Field position: after `assigned_to`, before `rice_code_id`

2. Create Lead API:
   POST /api/v1/leads/createLead
   Request Body:
   - Added optional field: `broker_id` (string, UUID format)
   - Can be null or omitted if no broker is associated

3. Update Lead API:
   POST /api/v1/leads/updateLead/:id
   Request Body:
   - Added optional field: `broker_id` (string, UUID format)
   - Can be set to null to remove broker association

4. Get Lead APIs:
   GET /api/v1/leads/getAllLeads
   GET /api/v1/leads/getLeadById/:id
   Response: All lead objects now include `broker_id` field

RESPONSE STRUCTURE:
===================
Lead Response Object:
{
  ...existing fields,
  assigned_to: string | null,
  broker_id: string | null,  // NEW FIELD
  rice_code_id: string,
  ...other fields
}
